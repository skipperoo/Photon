# Lensfun database snapshot

This directory contains a snapshot of the **lensfun** camera/lens database
(`*.xml`, `timestamp.txt`), used by Photon for automatic lens corrections
(distortion, lateral chromatic aberration and vignetting).

- Upstream: https://github.com/lensfun/lensfun (`data/db/version_1`)

- Snapshot taken from the Fedora `lensfun` package
  (`/usr/share/lensfun/version_1`), timestamp 1645386247.

The credit notice is also shown in the application's Lens panel.
